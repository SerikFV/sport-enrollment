# Атау келісімі

## Тармақтар (branches)
- `feature/<сипаттама>` — жаңа функция
- `bugfix/<сипаттама>` — қате түзету
- `docs/<сипаттама>` — құжаттама

## Commit-тер
- `feat: <сипаттама>` — жаңа функция
- `fix: <сипаттама>` — қате түзету
- `docs: <сипаттама>` — құжаттама
- `test: <сипаттама>` — тестілеу

## Тапсырмалар (issues)
- `[Feature] <сипаттама>`
- `[Bug] <сипаттама>`
- `[Task] <сипаттама>`
- `[Docs] <сипаттама>`

## PR (Pull Request)
- `[<түр>] <қысқаша-сипаттама>`
