# «Спорт» — спорт секциясына жазылу жүйесі

## Жоба туралы
Дене шынықтыру кафедрасының спорт секцияларына студенттерді онлайн жазу және топтарды басқару жүйесі.

## Мақсаты
- Өтініштерді өңдеу уақытын аптасына 6 сағаттан 1 сағатқа қысқарту
- Топтардың толықтығын 100% бақылау
- Қайта жазылуды болдырмау
- Қатысу есебін жүргізу

## Негізгі мүмкіндіктер
- Спорт секциясына онлайн жазылу
- Топтарды басқару
- Топ толықтығын бақылау
- Жаттығу кестесін жүргізу
- Хабарламалар
- Қатысу есебі
- Әкімшілік басқару

## Технологиялық стек
- Backend: Python 3.11 + FastAPI
- Frontend: React + Tailwind CSS
- Database: PostgreSQL 16
- Containerization: Docker
- CI/CD: GitHub Actions
